**AI-powered plant care & e-commerce platform**

A full-stack platform designed to provide plant owners with tools for diagnosis, shopping, and community interaction.

**Key Features**

* 🔐 JWT Authentication & Email OTP Verification
* 🧠 AI-powered plant disease diagnosis
* 🌿 Custom CNN model with 39 disease classes
* 🛒 E-commerce system with Cart, Wishlist & Checkout
* 👥 Community Posts & Comments
* 🗄️ PostgreSQL database
* 🐳 Dockerized deployment
* ⚡ Django REST Framework APIs

**Tech Stack**
