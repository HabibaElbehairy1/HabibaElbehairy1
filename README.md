### 📌 Featured Work

#### 🌱 [PlantCareSystem — Grovana](https://github.com/HabibaElbehairy1/PlantCareSystem)
> AI-powered plant care platform: diagnosis, e-commerce, and community.

- 🔐 **Auth:** JWT (access/refresh) + OTP email verification.
- 🤖 **AI:** Custom CNN (PyTorch) covering 39 plant-disease classes.
- 🛒 **Commerce:** Cart, Wishlist, Checkout, Order tracking.
- 🗣️ **Community:** Posts, Comments, and user interactions.
- ⚙️ **Ops:** Fully Dockerized and cloud-ready.

#### 🧩 [DesignPatterns](https://github.com/HabibaElbehairy1/DesignPatterns)

- **Creational:** Singleton, Factory, Builder, Prototype.
- **Structural:** Adapter, Decorator, Proxy, Facade.
- **Behavioral:** Observer, Strategy, State, Command.
- **Principles:** OOP, SOLID, Encapsulation, Polymorphism.
